# CyberSecurity Notes

This repository contains consolidated cybersecurity notes, daily logs, project documentation, reflections, and tasks. The structure is designed to provide a clear overview of learning progress and development in the cybersecurity field.

## Structure

- **DAILY LOG/**: Daily logs and progress tracking.
- **Projects/**: Documentation and notes related to cybersecurity projects.
- **Reflections/**: Personal reflections on learning and experiences.
- **Tasks/**: To-do lists and task management.
- **Rooms/**: Notes categorized by various cybersecurity rooms/topics, including content from TryHackMe.
    - `Red Teaming/`: Red Teaming specific notes.
    - `Cyber Security 101/`: Foundational cybersecurity concepts.
    - `JR Penetration Tester/`: Junior Penetration Tester learning path notes.
    - `RandomROOMS/`: Miscellaneous room notes.
    - `Web Application Pentesting/`: Web application penetration testing notes.
    - `WebFundamental/`: Web fundamentals notes.
- **Notes/**: General cybersecurity notes, cheatsheets, concepts, and tools.
    - `Concepts/`: Core cybersecurity concepts.
    - `Cheatsheets/`: Quick reference guides and cheatsheets.
    - `Tools/`: Documentation and usage of various cybersecurity tools.
    - `Misc/`: Miscellaneous notes and files.
- **Assets/**: Images and other assets used across the notes.

## Getting Started

To explore the notes, clone this repository and open it with your preferred markdown editor, such as Obsidian.
